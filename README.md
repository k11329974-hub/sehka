# Автоматическая установка личного WireGuard VPN

Скрипт для быстрой настройки безопасного частного VPN-сервера на Ubuntu с поддержкой клиентов для Windows, Android и iOS.

## Как запустить на сервере (VPS)

Подключитесь к вашему серверу на Ubuntu по SSH и выполните команду (замените `ВАШ_GITHUB_НИК` и `ИМЯ_РЕПО` на свои данные):

```bash
curl -sS https://githubusercontent.com | bash
```

## Что произойдет:
1. Система обновится до актуального состояния.
2. Автоматически установятся Docker и Docker-compose.
3. Развернется контейнер WireGuard.
4. Создадутся 3 готовых конфигурационных файла для ваших устройств.

## Как подключить Windows:
После выполнения скрипта зайдите в папку `~/wireguard/config/` на сервере, скопируйте текст из файла `peer1.conf` и вставьте его в официальный клиент WireGuard для Windows.
